# 🎮 Minecraft 1.21.1 Modpack (NeoForge)

Збірка модів для комфортної гри з друзями з автоматичною синхронізацією через **Git** та інтеграцією із запуском **TLauncher**.

* **Версія Minecraft:** `1.21.1`
* **Завантажувач модів:** `NeoForge 21.1.265`
* **Кількість модів:** 230 (Create + TFMG, Mekanism + реактори, Sable, Distant Horizons, Big Globe, Cataclysm, Iron's Spells та GPU/CPU оптимізації)

---

## ⚡ Як працює синхронізація збірки (`sync.bat` / `sync.ps1`)

Скрипт синхронізації автоматично підключається до запуску **TLauncher** (при першому запуску `sync.bat` він встановлює обгортку для `TLauncher.exe`).

Тепер **при кожному запуску TLauncher** (або при ручному запуску `sync.bat`) відкривається інтерактивне меню:

1. **Крок 1 — Вибір папки для завантаження збірки:**
   * Ви можете обрати будь-яку існуючу папку у `.minecraft\versions\` (за замовчуванням пропонується остання використана папка або `Test` — достатньо натиснути `Enter`).
   * Або створити нову папку версії (`[N]`), обрати папку через вікно Провідника Windows (`[B]`) чи ввести власний шлях (`[P]`).
   * Якщо синхронізація не потрібна, натисніть `0` — і TLauncher відкриється миттєво.
2. **Крок 2 — Вибір гілки або конкретного коміту:**
   * Скрипт автоматично отримує актуальний список усіх гілок (`mekanism-realistic-fixed`, `mekanism-realistic`, `main` тощо) та останніх комітів із GitHub.
   * Ви можете обрати коміт за номером зі списку (`1`, `2`, `3`...), обрати гілку (`B1`, `B2`...), або ввести хеш будь-якого коміту вручну.
3. **Крок 3 — Автоматичне завантаження та очищення:**
   * Скрипт завантажує обраний коміт у вказану папку, зберігаючи ваші світи (`saves/`) та мапи (`xaero/`).
   * Автоматично прибирає зайві або застарілі моди в `mods_backup/`, налаштовує `<НазваПапки>.json` / `<НазваПапки>.jar` та обирає цю версію у TLauncher.

## 🛠 Як відправляти свої зміни на GitHub (`push_changes.bat`)

1. Запустіть **`push_changes.bat`**.
2. Вкажіть гілку для відправки (або натисніть `Enter` для поточної гілки) та опис коміту.
3. Скрипт оновить індекси `Packwiz`, створить коміт і запушить зміни на GitHub.
