# 🎮 Minecraft 1.21.1 Modpack (NeoForge)

Збірка модів для комфортної гри з друзями з автоматичною синхронізацією через **Packwiz** та **Git**.

* **Версія Minecraft:** `1.21.1`
* **Завантажувач модів:** `NeoForge 21.1.265`
* **Кількість модів:** 175+ (Create + адони, Aeronautics, Cataclysm, Iron's Spells, Puffish Skills та оптимізації)

---

## ⚡ Як користуватись другу (швидкий старт)

### Перший запуск:
1. Встановіть у **TLauncher** версію **NeoForge 1.21.1** (або створіть профіль версії `2`).
2. Завантажте цей репозиторій собі на комп'ютер (або клонуйте через `git clone https://github.com/MrProper119/minecraft1.git`).
3. Запустіть файл **`sync.bat`**:
   * Скрипт автоматично завантажить усі моди прямо з офіційних серверів (CurseForge / Modrinth) у вашу папку `.minecraft\versions\2\mods`.
   * Скопіює актуальні файли конфігурацій `config/`.
4. Відкрийте TLauncher і запускайте гру!

### Оновлення збірки перед грою:
* Коли хтось оновив моди чи змінив конфіги, ви просто запускаєте **`sync.bat`**:
  * Він за пару секунд довантажить нові моди, оновить змінені конфіги та автоматично прибере видалені зі збірки моди (щоб уникнути крашів).

---

## 🛠 Як змінювати збірку та додавати моди

### 1. Додавання нового моду:
1. Запустіть файл **`add_mod.bat`**.
2. Вставте посилання на сторінку моду з **Modrinth** чи **CurseForge** (або просто напишіть назву моду, наприклад `jei`).
3. Скрипт автоматично додасть метадані моду.
4. Запустіть **`sync.bat`**, щоб цей новий мод одразу завантажився у вашу гру.
5. Запустіть **`push_changes.bat`**, щоб відправити оновлення на GitHub для друга.

### 2. Зміна налаштувань (конфігів):
1. Змініть потрібний конфіг безпосередньо у грі або в папці `.minecraft\versions\2\config`.
2. Запустіть **`push_changes.bat`**:
   * Він автоматично підтягне змінені конфіги з гри в репозиторій.
   * Зробить коміт і відправить зміни на GitHub.
3. Ваш друг запускає у себе `sync.bat` і моментально отримує ваші налаштування.

## 📁 Структура проєкту

| Файл / Папка | Призначення |
| :--- | :--- |
| `sync.bat` / `sync.ps1` | Синхронізація клієнта гри в 1 клік (завантажує моди та конфіги) |
| `add_mod.bat` | Зручне додавання моду через Packwiz без командного рядка |
| `push_changes.bat` | Забирає конфіги з гри та публікує оновлення на GitHub |
| `mods/` | Метадані модів (`.pw.toml`) з контролем версій і посиланнями на завантаження |
| `config/` | Спільні конфігурації всіх модів |
| `defaultconfigs/` | Налаштування за замовчуванням для нових світів |
| `pack.toml` / `index.toml` | Головні маніфести модпаку Packwiz |
| `packwiz.exe` | Вбудована утиліта керування модпаком |
